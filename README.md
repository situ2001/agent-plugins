# situ2001-plugins

Personal hooks and skills for Claude Code and Codex, packaged as the `situ2001` plugin.

The marketplace is named `situ2001-plugins`; skills use the `situ2001:` namespace.

## Claude Code

```bash
claude --plugin-dir .
```

Or inside a session: `/plugin` → install from folder.

## Codex

Install this folder as a local plugin (Use `skills/codex-plugin-setup` when installing or maintaining), then review and trust the hooks with `/hooks`.
